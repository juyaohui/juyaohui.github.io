Checkpoint（检查点）：在训练过程中，特定间隔或特定条件下保存的模型的快照。Checkpoints 可以用于从特定时间点恢复训练或用于模型评估。训练期间的检查点可以包含模型参数和优化器状态等信息。

Top-k（前 k 个）：在生成文本等任务中，top-k 参数用于限制在下一步中可能的选择数量。这种方法会根据概率分布选择前 k 个最有可能的选项，然后从中进行采样，而不是考虑所有可能的选项。

Beam search（束搜索）：在生成文本任务中，beam search 是一种搜索算法，它在每一步选择多个最有可能的选项，然后保留具有最高累积概率的选项。通过使用 beam search，可以找到比贪婪搜索更好的输出序列。

Batch size（批大小）：批大小是在训练过程中一次传递给模型的样本数量。较大的批大小可以增加训练效率，但也会占用更多的内存。较小的批大小可能会导致训练不稳定，并且增加训练时间。

Learning rate（学习率）：学习率决定了每次迭代中参数更新的步长。较小的学习率可以使训练更加稳定，但可能需要更长的时间来收敛。较大的学习率可能导致训练不稳定或错过最优解。

Gradient (梯度)：在深度学习中使用反向传播算法来计算网络参数的梯度。梯度是一个向量，指示网络中每个参数应该如何修改以使损失函数最小化。

Backward pass (反向传播)：在深度学习中，在每个训练步骤中计算网络参数梯度的过程。反向传播通过将损失函数梯度传递回每个单独的网络参数来计算梯度。

Overfitting (过拟合)：指模型在训练数据上表现良好，但在测试数据上表现较差的情况。过度调整模型参数可能导致模型过度拟合。这可以通过增加训练数据、采用正则化技术等方法来减少。

Regularization (正则化)：在训练过程中对网络参数进行约束以减少过拟合的技术。常见的正则化技术包括 L1、L2 正则化和 Dropout。在 L1 正则化中，将参数的绝对值添加到损失函数中，以鼓励网络学习到一个参数较少的解决方案。在 L2 正则化中，将参数的平方和添加到损失函数中，在训练过程中鼓励网络学习到一个权重小的解决方案。Dropout 是一种在训练过程中随机删除一些神经元的技术，以减少网络的复杂性和过拟合。

Early stopping (早期停止)：在训练过程中，一种减少过拟合的方法是在损失函数在验证集上的表现达到最佳时停止训练。这可以避免训练太多，导致模型过度拟合训练集。

Activation function (激活函数)：在神经网络中，激活函数将输入值转换为神经元的输出。常见的激活函数包括 sigmoid、ReLU、tanh 等。激活函数的选择对于模型的非线性建模能力至关重要。

Loss function (损失函数)：损失函数用于评估模型预测值与真实值之间的差异。训练过程中的目标是最小化损失函数。常见的损失函数包括均方误差 (MSE)、交叉熵 (Cross-Entropy) 等。

Optimizer (优化器)：优化器用于更新和调整模型的参数以最小化损失函数。常见的优化器包括随机梯度下降 (SGD)、Adam、Adagrad 等。不同的优化器具有不同的收敛速度和训练性质。

Model architecture (模型架构)：模型架构是指模型的整体结构和组成部分。包括网络的层数、层类型、神经元的连接方式等。模型架构的设计会直接影响模型的表达能力和训练效果。

Hyperparameters (超参数)：超参数是指在模型训练过程中需要手动设置的参数，而不是由模型自身学习到的参数。例如，学习率、批大小、正则化参数等都属于超参数。超参数的选择会影响模型的性能和训练效果。

Data augmentation (数据增强)：数据增强是通过对训练数据进行可控的变换来扩充数据集的方法。例如，在图像分类任务中，可以通过旋转、平移、缩放等变换来增加训练样本的多样性，以提高模型的泛化能力。
