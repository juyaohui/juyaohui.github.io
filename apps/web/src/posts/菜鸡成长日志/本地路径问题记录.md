现在问题已经解决了，问题的导致原因非常简单，就是由于模板中引用的一个插件没有相关配置。导致module无法识别命令

奇怪的是`npm run dev`可以运行，`npm run build`才会报错。应该是建立静态页面时才碰到该命令，正常本地状态下我并没有启用该命令

错误类似于下面这样
```bash
Module not found: Error: Can‘t resolve ‘xxxxx‘
```

就是文件中夹杂了无法识别的命令，在错误的报告部分细细查找是可以找到出现问题的地方的。按照提示修改就好。
